Automatización de Bitácoras de Base de Datos

Ministerio de Desarrollo Económico y Productivo, 2026

Solución para automatizar el procesamiento y la ejecución de bitácoras SQL mediante pipelines.

  • Azure DevOps
  • Azure Pipelines
  • Azure Repos
  • PowerShell
  • Oracle SQLPlus
  • Git
  • Windows Server
Problema
Las bitácoras SQL sobre bases de datos Oracle debían procesarse y ejecutarse con validaciones, por ambiente y con registro de lo ejecutado.
Solución
Un pipeline con agente self-hosted que valida archivos, elige el ambiente, maneja errores y registra cada ejecución.
Ver detalles
  • Diseño e implementación de la solución de punta a punta.
  • Notificaciones de errores automatizadas con PowerShell.
  • Gestión de los archivos procesados mediante Git.

BitácorasReport

Ministerio de Desarrollo Económico y Productivo, 2026

Aplicación web interna para visualizar y gestionar bitácoras pendientes.

  • Python
  • Flask
  • SQL Server
  • HTML
  • CSS
  • JavaScript
  • Waitress
  • PowerShell
  • Windows Server
Problema
Las bitácoras pendientes estaban en SQL Server y hacía falta una vista clara para consultarlas y priorizarlas.
Solución
Una aplicación web que lee SQL Server, filtra por equipo, etapa y estado, ordena por antigüedad y se actualiza sola.
Ver detalles
  • Filtros por equipos, etapas y estados.
  • Clasificación por antigüedad y actualización automática.
  • Versión portable desplegada en Windows Server, con configuración segura, pruebas automatizadas e inicio mediante tarea programada.
